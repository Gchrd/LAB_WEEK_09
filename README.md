## Project Description
Building User Interfaces using Jetpack Compose - CV Automation Application

This project has been enhanced with **CV Automation** functionality, transforming it into a comprehensive CV (Curriculum Vitae) builder application. Users can create, edit, and preview their professional CVs using a modern, intuitive interface built with Jetpack Compose.

### Key Features
- ✅ Personal Information Management
- ✅ Education Section with multiple entries
- ✅ Work Experience tracking
- ✅ Skills listing with proficiency levels
- ✅ Live CV Preview
- ✅ Material 3 Design
- ✅ Navigation between Edit and Preview modes
